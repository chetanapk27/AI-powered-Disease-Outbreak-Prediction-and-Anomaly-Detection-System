# Disease Outbreak Prediction and Anomaly Detection

## Overview

This project is an AI-powered public health monitoring system that analyzes health records, environmental factors, and social media trends to detect disease outbreaks and unusual health events.

## Features

* AI Hospital Admission Prediction (Random Forest)
* Outbreak Risk Assessment
* Isolation Forest Anomaly Detection
* Live Weather Integration
* Live AQI Monitoring
* Social Media Trend Analysis
* GIS Disease Hotspot Mapping
* Multi-Page Streamlit Dashboard

## Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-Learn
* Folium
* Open-Meteo API

## Project Structure

* Dashboard
* AI Prediction
* Environmental Analysis
* Social Media Trends
* Disease Hotspots
* Outbreak Alerts
* Anomaly Detection

## Run Locally

pip install -r requirements.txt
python -m streamlit run app.py
